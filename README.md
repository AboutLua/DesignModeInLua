# DesignModeInLua

<!-- repository-classification:start -->
## 仓库定位

- **类别：** Lua 语言与设计模式学习参考
- **状态：** 示例型仓库
- **用途：** 使用 Lua 展示创建型、结构型、行为型及部分 J2EE 设计模式。

仓库重点是通过可运行示例理解模式的结构、职责和协作关系，而不是提供可直接用于所有生产项目的框架。`patterns/` 按模式类别组织示例，`Main.lua` 是主要运行入口。

设计模式本身具有长期参考价值；实际项目中应结合 Lua 的动态语言特性进行取舍，避免为了套用模式而增加不必要的抽象。
